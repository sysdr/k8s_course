PostgreSQL High Availability Cluster Deployed Successfully!

1. Get the PostgreSQL connection information:

   Read-Write Service (Primary):
   export POSTGRES_HOST=$(kubectl get svc postgres-rw -n database -o jsonpath='{.spec.clusterIP}')
   export POSTGRES_PORT=5432

   Read-Only Service (Replicas):
   export POSTGRES_RO_HOST=$(kubectl get svc postgres-ro -n database -o jsonpath='{.spec.clusterIP}')

   Through PgBouncer (Recommended):
   export PGBOUNCER_HOST=$(kubectl get svc pgbouncer -n database -o jsonpath='{.spec.clusterIP}')

2. Get the PostgreSQL password:

   export POSTGRES_PASSWORD=$(kubectl get secret postgres-credentials -n database -o jsonpath='{.data.password}' | base64 -d)

3. Connect to PostgreSQL:

   kubectl run psql-client --rm -it --image=postgres:16-alpine -- \
     psql -h $PGBOUNCER_HOST -U postgres -d appdb

4. Access the Dashboard:

   kubectl port-forward -n services svc/frontend 8080:80

   Then open: http://localhost:8080

5. View logs:

   kubectl logs -n database -l app=postgres -f

6. Check replication status:

   kubectl exec -it postgres-0 -n database -- \
     psql -U postgres -c "SELECT * FROM pg_stat_replication;"

For more information, visit: https://github.com/your-org/postgres-k8s
