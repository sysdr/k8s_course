================================================================================
DEPLOYMENT WORKFLOW
================================================================================

1. Developer commits to Git repository
2. ArgoCD detects changes (3-minute poll interval)
3. ArgoCD compares Git state vs Cluster state
4. ArgoCD automatically syncs differences
5. Metrics Aggregator polls ArgoCD status
6. Event Processor receives webhook notifications
7. Dashboard displays real-time deployment status
8. Prometheus scrapes metrics
9. Grafana visualizes deployment trends

================================================================================
GETTING STARTED
================================================================================

1. Create cluster:       cd scripts && ./setup-cluster.sh
2. Install ArgoCD:       ./install-argocd.sh
3. Build images:         ./build.sh
4. Deploy platform:      ./deploy.sh
5. Setup monitoring:     ./monitoring-setup.sh
6. Access ArgoCD UI:     kubectl port-forward svc/argocd-server -n argocd 8080:443
7. Access Dashboard:     kubectl port-forward svc/dashboard -n gitops-apps-prod 8081:80
